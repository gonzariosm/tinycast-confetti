# Confetti for Tinycast 🎉

Celebrate a finished task with a five-second burst of native confetti across your
Mac's displays. The overlay lets clicks pass through, leaves keyboard focus alone,
and exits when the animation ends.

Built with Swift, AppKit and Core Animation. No browser, Electron, account,
network requests or persistent background process at runtime.

## Install in Tinycast

**From GitHub:** open **Settings → Extensions → Install from GitHub** and paste:

```text
https://github.com/gonzariosm/tinycast-confetti
```

Tinycast builds the extension using Node and a package manager. The native helper
is already included for Apple Silicon and Intel; Xcode is not needed to install it.

**Without Node:** download `tinycast-confetti-v1.0.0.zip` from
[Releases](https://github.com/gonzariosm/tinycast-confetti/releases/latest), unzip it,
then choose **Settings → Extensions → Add from folder** and select the extracted
`tinycast-confetti` folder. It contains `package.json`, `confetti.js` and `assets/`.

Enable Extensions, search for **Confetti**, and press Return. You can assign a
shortcut or favorite from Tinycast's extension settings.

## Compatibility

- Tested with Tinycast 0.12.11 on Apple Silicon.
- The helper is a universal macOS binary targeting macOS 13 and later. Intel is
  built but has not been tested on physical hardware.
- Uses the Raycast extension format and standard APIs. Raycast itself has not been
  tested, and this project is not listed in the Raycast Store.
- The helper is ad-hoc signed, not Apple-notarized. Managed Macs may restrict it.

No Accessibility, Screen Recording, or Automation permissions are requested. The
helper briefly creates transparent, nonactivating windows on all attached screens.
No settings, clipboard contents, screenshots or personal files are read.

## Build from source

Requires macOS, Node 22 or later, and Apple Command Line Tools with Swift 6.

```sh
npm ci --ignore-scripts
npm run typecheck
npm run build:native
npm run build:icon
npm run build
npm run package
```

The release ZIP and its SHA-256 checksum appear in `release/`. The checked-in
`assets/confetti` binary is built from `native/Confetti.swift`; regenerate and commit
it whenever the native implementation changes. The icon is original artwork
generated by `scripts/make-icon.swift`.

The extension closes the launcher, runs the native helper, and waits for it to
finish. It reports launch failures through the launcher's standard toast. The
native process exits after five seconds; the command also has a ten-second timeout.

To remove it, uninstall **Confetti** in Tinycast's Extensions settings.
